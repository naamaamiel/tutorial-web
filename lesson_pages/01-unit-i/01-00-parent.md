# Unit I: Introduction

This unit introduces you to the course and gets you started with gem5. 

> By the end of this unit, you will be able to:
> 
> - **Download** and **build** gem5.
> - **Explain** how gem5 simulates components and the passage of time.
> - **Create** and **run** simple Python configuration scripts using demo components.
