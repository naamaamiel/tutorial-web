# Unit III: Intermediate gem5 features

Now that you have some basic simulation experience, this unit explores features of gem5 that may be of interest.

> By the end of this unit, you will be able to:
> 
> - **Determine** appropriate simulation uses for Syscall Emulation (SE) and Full-System (FS) mode.
> - **Facilitate** communication between the guest application and the simulator using customized exit events and m5ops annotations.
> - **Create** and **use** traffic generators in place of processor models to simulate memory accesses.
