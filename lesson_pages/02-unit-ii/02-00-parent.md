# Unit II: Beginning simulation

In this unit, you'll transition from using demo materials to exploring the existing components in gem5.

> By the end of this unit, you will be able to:
> 
> - **Construct** a Python configuration script using standard library components and gem5 resources.
> - **Modify** existing gem5 components (cores, caches, and memory) in Python using object-oriented design practices such as extension and instantiation.
> **Navigate** and **interpret** the output of gem5 simulations.
